Privacy Policy

Split Flap Display (the "Extension") — Effective date: July 2026

1. Introduction

This Privacy Policy describes how the Split Flap Display browser extension (the "Extension," "we," or "us") handles information in connection with your use of the Extension. It is intended to give you a complete and accurate account of what data the Extension touches, where that data goes, and the choices available to you.

By installing and using the Extension, you agree to the practices described in this Policy. If you do not agree with these practices, please do not install or use the Extension.

2. Summary

The Extension operates entirely on your local device. We do not operate any backend server, and we do not collect, receive, transmit to ourselves, or otherwise have access to any data generated by your use of the Extension. Where the Extension communicates over the network, it does so directly between your browser and the specific third-party service required for the feature in question, and only when you have enabled and, where applicable, configured that feature yourself.

4. Browser Permissions

4.1 The "tabs" permission. The optional Time on Sites feature requires the ability to determine which website is displayed in the active tab in order to measure time spent per site. This is the sole purpose of the tabs permission requested by the Extension. It has no effect unless you affirmatively enable the feature in Settings, where it is disabled by default; disabling it at any time immediately halts further tracking. The Extension does not access page content, form data, or tabs other than the currently active one, regardless of whether this feature is enabled.

4.2 The "alarms" permission. Used solely to periodically persist and prune data associated with the Time on Sites feature. This permission has no effect if that feature is disabled.

5. Third-Party Services

The Extension communicates with the following services, solely when the corresponding feature has been enabled and, where applicable, configured by you:

  • Open-Meteo — receives approximate coordinates; no authentication required.
  • GitHub REST API — receives the username you provide; no authentication required.
  • Chess.com Public API — receives the username you provide; no authentication required.
  • MonkeyType Public API — receives the username you provide; no authentication required.
  • WakaTime API — receives an API key generated and controlled by you.
  • Steam Web API — receives an API key and Steam ID generated and controlled by you.
  • CoinGecko Public API — receives the coin list and currency you configure; no authentication required.
  • Nager.Date Public API — receives the current date and your selected country code; no authentication required.
  • Google Search — receives search queries you submit while using Search Mode.

Each of these services is governed by its own privacy policy and terms of service. We do not control, and are not responsible for, the data practices of these third parties. Our relationship with each service is limited to the direct API request initiated by your browser as a result of your configuration.

6. Compliance with the Digital Personal Data Protection Act, 2023 (India)

As the Extension does not transmit personal data to any server under our control, the obligations applicable to a Data Fiduciary under India's Digital Personal Data Protection Act, 2023 ("DPDP Act") are, in most respects, not engaged, as no such collection or processing occurs on infrastructure we operate. Nonetheless, in relation to the limited categories of data the Extension does handle locally, the Extension has been designed in accordance with the DPDP Act's foundational principles:

  • Consent — the most sensitive optional feature, Time on Sites, is disabled by default and requires an explicit, separate opt-in.
  • Purpose Limitation — each category of data is used exclusively for the specific feature it supports.
  • Data Minimization — the Time on Sites feature retains hostnames only.
  • Storage Limitation — data associated with Time on Sites is automatically deleted after three days.
  • Grievance Redressal — concerns may be directed to the contact in Section 9.

7. Your Rights and Choices

Because no data is retained outside your own device:

  • Access and Deletion — uninstalling the Extension immediately removes all data stored locally by it. Individual settings may also be cleared at any time from the Settings page, or extension storage may be cleared directly via chrome://extensions.
  • Withdrawal of Consent — disabling the Time on Sites feature immediately halts further data collection; any previously retained data for that feature is deleted automatically within three days regardless.

8. Children's Privacy

The Extension is not directed toward, and is not knowingly used to collect information from, children.
